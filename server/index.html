    Turn on Developer Mode

    Roku's official way to add your own app. Nothing is changed or unlocked on your account, and you can turn it off again any time the same way.

    1. Pick up the Roku remote and go to the Roku home screen.
    2. Press these buttons in order, about one per second:
      Home Home Home  ·  Up Up  ·  Right Left Right Left Right
      A Developer Settings screen appears. If it doesn't, press Home and try again a little slower.
    3. Write down the address it shows (like http://192.168.1.50). That's your TV's address.
    4. Choose Enable installer and restart, then I Agree to the developer agreement.
    5. Make up a password (letters and numbers) and choose Set password and reboot. You'll type it here once to install SaverSwap.
    6. The TV restarts. Come back to this page and tap I did it, check again.

    Already turned it on before but forgot the password? Do the same button sequence; the screen lets you set a new one.
